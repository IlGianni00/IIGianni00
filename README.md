# Thomas Giannini

MSc in Psychology, with a focus on cognitive neuroscience and neuropsychological rehabilitation.

My research interests include cognitive neuroscience, neuropsychology, cognitive aging, executive functions, cognitive reserve, and reproducible quantitative research. I am particularly interested in combining behavioral and neuropsychological methods with neuroimaging and psychophysiological approaches.
